# Hacklonega

The site for Hacklonega, the Hacktoberfest Hack Day at the University of North Georgia in Dahlonega on October 24, 2026. The event is over, so the site is now its recap: the eight projects and their awards, photos from the day, and credits. The full photo set is in [MLH's gallery](https://majorleaguehacking.smugmug.com/Event-Photos/Hacktoberfest-2026/Hacktoberfest-hack-day-dahlonega-x-univ-north-ge-b19f118e8e/n-rM8cB6), and every project is on the [MLH submissions page](https://www.mlh.com/events/hacktoberfest-hack-day-dahlonega-x-univ-north-georgia/submissions).

The application is in [CodeHawks-FrontEnd](CodeHawks-FrontEnd/README.md). [CodeHawks-Backend](CodeHawks-Backend/README.md) explains why this static site has no API.

The site is deployed and live at [hacklonega.dev](https://hacklonega.dev/). Development followed the three phases in the [implementation plan](PLAN.md): website and visual iteration, GitHub/AWS automation, then domain and Cloudflare launch.
